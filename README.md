# PlaywrightLearningBatch

A JavaScript learning repository with chapter-based examples, TypeScript practice files, and Playwright automation notes.

## Overview

This repository is structured as a study guide for JavaScript and TypeScript fundamentals. It includes beginner to intermediate examples covering syntax, core language features, object-oriented programming, asynchronous patterns, and automation.

## Chapters

### JavaScript Fundamentals
- `Chapter_01_Basics/`
  - Introduction to JavaScript, setup validation, and basic scripts.
- `Chapter_02_JavaScript_Concepts/`
  - Identifier rules, naming conventions, and core language concepts.
- `Chapter_03_Identifier_Literals/`
  - Literals, comments, and identifier examples.
- `Chapter_04_JavascriptsConcepts/`
  - `var`, `let`, `const`, hoisting, scope, and the Temporal Dead Zone.
- `Chapter_05_literals/`
  - Primitive values, numbers, strings, template literals, and special cases.
- `Chapter_06_double_triple_equal/`
  - Operators, equality comparisons, logical operators, and ternary expressions.
- `Chapter_07_IfElse/`
  - Conditional logic with `if`, `else if`, `else`, and real-world examples.
- `Chapter_08_SwitchStaement/`
  - `switch` statements, `default` cases, and grouped logic.
- `Chapter_09_Userinput/`
  - Basic user input handling and console interaction patterns.
- `Chapter_10_loops/`
  - Loop constructs including `for`, `while`, `do-while`, `for-of`, and `for-in`.
- `Chapter_11_Array/`
  - Arrays, indexing, iteration, transformation, and searching techniques.
- `Chapter_12_Functions/`
  - Function declarations, expressions, arrow functions, closures, higher-order functions, and interview exercises.
- `Chapter_13_String/`
  - String methods, manipulation, searching, and formatting.
- `Chapter_14_Objects/`
  - Object literals, property access, destructuring, spread syntax, getters/setters, and methods.
- `Chapter_15_2D_Array/`
  - Two-dimensional arrays, matrix operations, and pattern exercises.

### Asynchronous JavaScript
- `Chapter_16_callback/`
  - Callback patterns, asynchronous callbacks, and callback hell examples.
- `Chapter_17_promise/`
  - Promises, chaining, error handling, and `Promise.all()`.
- `Chapter_18_Async_Await/`
  - `async`/`await`, error handling, and asynchronous control flow.

### Automation and Advanced Topics
- `Chapter_19_Playwright/`
  - Playwright setup, browser automation, and end-to-end testing examples.
- `chapter_33_Playwrightfundmental/`
  - Playwright fundamentals, configuration, and practical browser automation exercises.
- `Chapter_20_oopsBasics/`
  - Object-oriented programming concepts such as classes, encapsulation, inheritance, and modules.
- `Chapter_27_Typescript/`
  - TypeScript basics, type annotations, interfaces, and practical examples.
- `Chapter_28_Typescript_Interface/`
  - Interface definitions, readonly properties, and advanced TypeScript patterns.

## Getting Started

1. Open the repository in Visual Studio Code.
2. Run JavaScript or TypeScript files with Node.js.
3. Use `ts-node` or compile TypeScript with `tsc` for TypeScript files.

This repository is focused on practical JavaScript and TypeScript learning, including:
